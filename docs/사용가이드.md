# 일일서류 사용 가이드

건설현장 안전관리자가 매일 쓰는 서류 5종을 입력하고, A4로 인쇄하고, PDF로 보관하는 프로그램입니다.

① 안전교육일지 · ② T.B.M 사진대지 · ③ 안전 순회 점검표 · ④ 무인 타워크레인 점검일지 · ⑤ T.B.M 일지(위험성평가)

---

## 1. 시작하기

### 화면 구성
- **왼쪽 메뉴**: 서류 ①~⑤, 보관함, 설정. 맨 위 "오늘 날짜로 이동" 버튼, 맨 아래 현재 데이터 폴더 경로.
- **상단 바**: 날짜 이동(◀ ▶, 달력, 오늘), 확대/축소, "오늘 서류 PDF 만들기", "N종 일괄 인쇄".
- **가운데**: A4 서류 화면. 칸을 눌러 바로 입력합니다. 인쇄하면 화면 모양 그대로 나옵니다.

### 처음 한 번 해 둘 일 (설정)
1. **공사현황**: 현장명, 업체/공종명, 공사 개요 등을 입력합니다. 모든 서류와 AI 생성에 쓰입니다.
2. **결재란 도장 이미지 등록**: 도장 이미지(PNG/JPG/WEBP)를 칸별로 등록해 두면 서류마다 켜고 끌 수 있습니다.
3. **근로자 명단 등록**: 직종과 성명을 등록해 두면 ⑤ T.B.M 일지의 서명표를 "명단 불러오기"로 채웁니다.
4. **출력 서류 선택**: 현장에 타워크레인이 없으면 ④를 체크 해제하세요. 일괄 인쇄·PDF·백업에서 빠집니다.
5. **설정 저장**을 반드시 누릅니다. 저장하지 않으면 바뀐 설정이 적용되지 않습니다.

### 저장과 이월
- 입력하면 **약 1초 뒤 자동 저장**됩니다. 별도의 저장 버튼은 없습니다.
- 처음 여는 날짜는 **전날 내용이 이월**되어 시작합니다(현장 정보, 인원, 교육 대상 등). 매일 처음부터 다시 쓸 필요가 없습니다.
- 데이터는 "데이터 폴더"에 날짜별로 저장됩니다(`연/월/날짜/data.json`, 사진 포함). 이 폴더만 복사해 두면 백업이 됩니다.

## 2. 서류별 사용법

### ① 안전교육일지
- 교육 인원은 **자동 합산**됩니다(설정의 구분 목록 기준). 직접 고치면 "수동"이 되고, "자동" 버튼으로 되돌릴 수 있습니다.
- 교육내용은 6줄입니다. **교육내용 머리글의 AI 버튼**으로 생성·개선·추가를 할 수 있습니다(4장 참고).
- "교육내용 번호 정렬" 버튼으로 번호를 맞춥니다.

### ② T.B.M 사진대지
- 사진 6칸. **여러 장 선택, 클릭해서 교체, Ctrl+V 붙여넣기, 끌어다 놓기**, 칸끼리 위치 교환, 삭제가 됩니다.
- 사진은 20MB 이하의 jpg/png/webp 입니다.

### ③ 안전 순회 점검표
- 점검결과(양호/미흡/해당없음)는 칸을 누르면 ○가 표시되고, **한 번 더 누르면 해제**됩니다.
- "18개 항목 모두 양호", "점검결과 전체 해제" 버튼이 있습니다. 감리단이 수기로 표시하는 현장은 전체 해제 후 인쇄하세요.
- 새 날짜의 점검결과 기본값(양호/비움)은 **설정 → 순회 점검표 점검결과 기본값**에서 정합니다.

### ④ 무인 타워크레인 점검일지
- 20개 항목 양호/불량과 비고를 입력합니다. "20항목 모두 양호" 버튼이 있습니다.

### ⑤ T.B.M 일지(위험성평가)
- 금일 작업구간과 위험성평가 표(최소 4행)를 입력합니다. 상·중·하는 ○로 표시됩니다.
- 아래 서명표는 "명단 불러오기"로 채웁니다.
- 표의 **AI 버튼**으로 장비/도구, 위험요인, 감소대책을 생성할 수 있습니다(4장 참고).
- **생성 행 수**: "AI로 위험성평가 생성" 옆에서 행 수를 정합니다. 기본은 "자동(3~6행)"이고 3~8행을 고를 수 있습니다. 8행까지는 A4 1쪽에 들어갑니다. 기간 일괄 생성 옵션에도 같은 선택이 있습니다.
- **행 삭제**: 각 행 감소대책 칸의 **"삭제"** 버튼으로 원하는 행을 지웁니다. 표는 최소 4행이라 4행일 때는 **"비우기"**로 내용만 지웁니다. 잘못 지웠다면 "이전 위험성평가 되돌리기"로 한 단계 복구합니다.

## 3. 인쇄·PDF·백업

### 인쇄
- 각 서류의 **"이 서류 인쇄"**: 그 서류 1장을 인쇄합니다.
- 상단 **"N종 일괄 인쇄"**: 설정에서 선택한 서류를 한 번에 인쇄합니다.
- 인쇄 화면에는 버튼·테두리 같은 화면용 표시가 나오지 않습니다.

### T.B.M 일지 일자 조정 (전날 출력용)
작업 전날 미리 출력해 두고, 아침에 작업자가 읽은 뒤 서명하는 방식으로 쓰는 현장을 위한 기능입니다.
- **일자 비우고 인쇄**: 연도와 년·월·일 글자만 인쇄하고 월·일은 빈칸으로 둡니다. 체크하면 화면의 일자도 같은 모양으로 바뀌어 인쇄될 모양을 미리 볼 수 있습니다.
- **일자 이동(일)**: 출력 일자를 문서 일자에서 며칠 이동합니다. 전날 출력할 때 **+1(다음날)**.
- 인쇄물에만 적용되고 저장된 데이터는 바뀌지 않습니다. 비움을 켜면 이동값은 무시됩니다.

### PDF와 백업
- **"오늘 서류 PDF 만들기"**: 선택한 서류를 한 파일 PDF로 만들어 날짜 폴더에 저장합니다.
- 설정에서 **추가 백업 폴더**(예: NAS, 외장 하드)를 지정하면 자동/수동 백업이 됩니다.
- **보관함**에서 지난 날짜를 연·월로 찾고, 날짜·키워드로 검색하고, PDF를 열 수 있습니다.

### 화면 확대/축소
- 상단 `－` `＋` 또는 **Ctrl + 마우스 휠**로 50~200% 조절, "너비 맞춤"으로 창 폭에 맞춥니다. 화면만 바뀌며 인쇄 크기에는 영향이 없습니다.

## 4. AI로 내용 만들기

### 기본 원칙
- **버튼을 눌렀을 때만** 동작합니다. 자동으로 호출되지 않습니다.
- 결과는 항상 **미리보기를 확인한 뒤 적용**합니다. 마음에 안 들면 "되돌리기", "다시 생성"을 쓰세요.
- 생성 중에는 누른 AI 버튼이 돌아가고 처리 중인 칸이 강조되며, 화면 위쪽에 따라다니는 **진행 바**에서 취소할 수 있습니다. 다른 AI 버튼은 흐려져 눌리지 않습니다. 끝나면 미리보기 위치로 화면이 자동 이동합니다.
- 근로자 이름·도장 같은 개인정보는 AI에 보내지 않습니다. 공사현황·작업구간·날씨 같은 현장 정보는 전송됩니다. 외부 서비스 엔진을 쓸 때는 이 점을 알고 쓰세요.

### 엔진 연결 (설정 → AI 연결 설정)
| 엔진 | 설명 |
|---|---|
| Hermes | 로컬 Hermes 서버 |
| LM Studio / Ollama | 내 PC에서 돌리는 로컬 모델 |
| OpenCode / OpenRouter / DeepSeek / Gemini | 외부 서비스(API 키 필요, 키는 별도 파일에 저장) |
| Claude Code CLI | PC에 `claude`가 설치되고 로그인되어 있으면 사용 가능 |
| Claude MCP | 앱이 호출하지 않고, Claude 앱에서 이 프로그램의 데이터를 읽고 쓰는 방식(아래 참고) |

- 엔진을 고른 뒤 **"연결 테스트"로 확인하고, 반드시 "설정 저장"**을 누르세요. 저장하지 않으면 테스트는 성공해도 실제 생성은 이전 엔진으로 갑니다.

### 어디서 쓰나
- **① 교육내용**: 머리글 AI 버튼 → 생성/개선/추가 선택.
- **⑤ 위험성평가**: "AI로 위험성평가 생성"(표 전체), 장비/도구·유해위험요인·감소대책 열 머리글 AI(누르면 **"빈 칸만 채우기"**와 **"열 전체 다시 생성(덮어쓰기)"** 중 고릅니다. 덮어쓴 내용은 "이전 위험성평가 되돌리기"로 한 단계 복구됩니다), 각 칸 AI(그 행만).

### Claude MCP 연동(선택)
Claude 앱에서 "오늘 공사현황을 바탕으로 교육내용과 위험성평가를 작성해줘"처럼 시켜서 데이터를 채우는 방식입니다. 설정의 "Claude MCP 연동 안내" 카드에 등록용 설정 내용이 있으니 복사해서 Claude 설정에 직접 추가하세요(앱이 설정 파일을 자동으로 바꾸지 않습니다).

### 위험성평가 라이브러리 (자동 누적·재사용)
- **쌓이는 방법**: AI로 만든 위험성평가를 **적용**하면 장비/도구·유해위험요인·재해형태·등급·감소대책이 이 PC에 자동으로 쌓입니다. 직접 고친 행은 입력을 멈추고 약 10초 뒤(또는 날짜·서류를 옮기거나 인쇄할 때) 자동으로 쌓이고, 바로 담고 싶으면 그 행의 **"보관"** 버튼을 누릅니다. 장비/도구·유해위험요인·감소대책이 모두 있는 행만 저장되고, 같은 내용은 중복 없이 사용 횟수만 늘어납니다.
- **AI가 참고**: AI로 생성할 때 비슷한 과거 항목이 참고 자료로 함께 전달되어 문구가 일관되게 나옵니다. 설정의 **"AI 생성 시 위험성평가 라이브러리 참고"**로 끌 수 있습니다. 외부 서비스 엔진을 쓰면 이 참고 항목도 함께 전송됩니다.
- **직접 골라 넣기**: ⑤ 화면과 일괄 검토 창의 **"라이브러리에서 추가"** 버튼으로 종류별·검색으로 골라 표에 넣습니다. 빈 행부터 채워지고, 이미 같은 항목이 있으면 건너뜁니다.
- **관리**: 설정의 **"위험성평가 라이브러리"** 카드에서 검색, 종류별 보기, 수정, 삭제, 종류 일괄 변경, 전체 비우기를 합니다. 바로 저장되므로 "설정 저장"은 필요 없습니다. 종류는 교육일지의 공종을 따르고 없으면 "미분류"입니다. 데이터 폴더의 `risk_library.json`에 저장되며, 이 파일을 복사하면 다른 PC로 옮길 수 있습니다.

## 5. T.B.M 일지 한꺼번에 만들기 (주간/월간)

### 공정표 입력
설정 → **공정표**에 기간별 작업(시작일, 종료일, 작업내용, 주요장비)을 입력합니다. AI가 날짜별 작업구간을 정할 때 참고합니다.

### 기간 일괄 생성 (⑤ 화면)
1. **"기간 일괄 생성"** → 주간(7일) 또는 월간(30일), 시작일을 고릅니다. 빼고 싶은 날짜는 칩을 눌러 해제합니다.
2. **생성 시작**: 날짜별로 하나씩 AI가 만듭니다(이때는 아무것도 저장되지 않습니다).
3. **검토 창**에서 날짜를 눌러 내용을 고칩니다. 표의 AI 버튼으로 칸·열 단위로 다시 만들 수 있고, "A4 미리보기" 탭에서 인쇄될 모양을 봅니다.
4. **선택 날짜 적용**: 체크한 날짜만 저장됩니다. 이미 내용이 있는 날짜는 기본으로 체크가 꺼져 있고, 덮어써도 이전 위험성평가는 백업됩니다.
5. **선택 날짜 TBM일지 인쇄**: 최대 31장을 한 번에 인쇄합니다(일자 비움/이동 옵션 적용).

### 기간 확인·인쇄 (이미 저장된 날짜)
⑤ 화면의 **"기간 확인·인쇄"**로 저장된 T.B.M 일지를 다시 불러와 확인·수정·인쇄합니다. "저장" 체크와 "인쇄" 체크가 따로 있어서, 인쇄만 하고 저장은 하지 않을 수도 있습니다.

## 6. 자주 묻는 질문

**Q. AI 연결 테스트는 성공했는데 다른 엔진으로 생성돼요.**
설정을 저장하지 않았기 때문입니다. "설정 저장"을 누르세요.

**Q. 새 날짜가 점검결과 ○ 없이 열려요.**
설정의 "순회 점검표 점검결과 기본값"이 "비움"으로 되어 있습니다.

**Q. 인쇄 미리보기에서 서류가 잘리거나 2장으로 나뉘어요.**
인쇄 창에서 용지 A4, 배율 100%(또는 "실제 크기"), 여백 "없음/기본"으로 설정하세요. 머리글/바닥글 출력은 끄세요.

**Q. 타워크레인이 없는 현장입니다.**
설정 → 출력 서류 선택에서 ④를 해제하세요.

**Q. 데이터를 다른 PC로 옮기고 싶어요.**
설정에서 데이터 폴더를 확인하고, 그 폴더 전체를 복사해 새 PC의 같은 위치에 두거나 새 PC의 설정에서 데이터 폴더를 지정하세요.

**Q. Claude Code CLI 연결이 실패해요.**
PC에 Claude Code가 설치되어 있는지(`claude` 명령), 로그인이 되어 있는지 확인하세요. 실행 경로를 직접 지정할 수도 있습니다.
